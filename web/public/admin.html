6. Административная страница

Весь раздел /api/admin доступен только ролям admin и owner. Под клиентом страница ответит 403 — и покажет это текстом. Цену услуги меняет только owner.

Все записи — GET /api/admin/appointments
—
Смена статуса — POST /api/admin/appointments/:id/status

no_show увеличивает счётчик неявок и после порога блокирует клиенту онлайн-запись.

Услуги — GET/POST/PATCH/DELETE /api/admin/services

Новая услуга — POST /api/admin/services

Правка услуги — PATCH /api/admin/services/:id

Цена уходит в запрос только с отметкой «отправить цену»: администратору API ответит 403, владельцу — сохранит.
